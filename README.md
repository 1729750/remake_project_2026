# 프로토타입 소개

기존 아이디어를 플레이 할 수 있는 정도의 프로토타입을 제작 완료했습니다.

> 현재 전투 시연만 구현되어 있고, 시작 버튼이나 재시작 버튼, 전투 종료 후 전리품 등은 구현되어있지 않습니다.

---

## 화면 설명

- 정 가운데의 **초록색 원**이 현재 턴을 나타내고, 아래에 있는 **3개의 직사각형**이 플레이어의 큐, **4개의 직사각형**이 플레이어의 패입니다.
- **주황색 원**의 숫자는 현재 코스트를, **하늘색 원**의 숫자는 현재 방어력을 의미합니다.
- 중앙 HP바를 기준으로 위에 있는 것들은 적의 정보입니다.

---

## 카드 설명

카드는 그림 위에 임시로 이모티콘과 숫자를 통해 의미를 표현했습니다. 각 이모티콘은 다음을 의미합니다:

| 이모티콘 | 의미 |
|--------|------|
| 🗡 | 그 숫자만큼의 데미지를 줍니다 |
| 🛡️ | 그 숫자만큼의 방어력을 얻습니다 |
| ⚙️ | 얻는 방어력에 이 수치만큼 더합니다. 얻는 방어력이 0 미만으로 내려가지 않습니다. |
| ✊ | 적에게 주는 데미지에 이 수치만큼 더합니다. 주는 데미지가 0 미만으로 내려가지 않습니다. |
| 💔 | 데미지를 1.2배로 받습니다. |
| 🥀 | 주는 데미지가 0.8배가 됩니다. 현재 카드 풀에는 들어가있지 않습니다. |
| ⏱ | 카드 발동까지 필요한 남은 턴의 수입니다. 카드를 사용한 턴의 다음 턴부터 계산합니다. |

카드 오른쪽 위의 **주황색 원** 위의 수치는 카드의 코스트입니다.

---

## 진행과정

1. 구동 시 바로 전투가 시작됩니다. **3초의 준비 시간** 후에 게임이 시작되며, **1턴에 1초**의 제한시간이 존재합니다.
2. 턴 중에, `Q` `W` `E` `R`로 패의 카드를 하나 선택할 수 있습니다. 최대 선택 가능한 카드의 개수는 1장입니다.
3. 턴의 제한시간이 전부 지나면, 선택한 카드의 코스트를 지불할 수 있는지 확인하고 가능하다면 그 카드를 큐로 옮깁니다. 불가능하다면, 그 카드를 사용하지 않습니다.
4. 사용한 카드의 빈자리는 바로 덱의 다음 카드로 채워집니다.

적, 플레이어의 체력은 **100**이며, 어느쪽이든 이 수치가 0이 되면 게임이 종료됩니다.

## 개선안

프로토타입을 제작해보니 기획에서 개선할 점을 많이 발견할 수 있었습니다.

### 1. 코스트가 진행을 방해함

현재 기획상 코스트가 한 턴에 1 씩 차오르는 구조인데, 코스트가 차오를 때 까지 플레이어가 게임에 상호작용할 수 있는 요소가 부재하여 집중이 자주 끊깁니다.

이를 해결하려면 코스트와 별개의 행동(드로우, 덱 셔플, 혹은 qte식 방어/회피 시스템)을 도입하거나, 코스트 수급 방식을 바꾸어야 (n턴에 m개 식) 할 것 같습니다.

### 2. 적 행동이 빠름

원래 기획상 서로의 행동을 보고 그에 맞게 행동하는 것을 재미 요소로 잡았는데, 현재 밸런스를 전혀 고려하지 않은 테스트 카드임을 고려해도 게임의 원활한 진행을 위해 턴을 빠르게 할 수록 플레이어가 적 행동에 반응하는 것이 불가능합니다.

이를 해결하려면 공격과 방어 카드 사이의 쿨타임에 확실한 차등을 두어 방어 카드를 사용하는 쪽에게 적의 공격 카드를 읽고 반응할 충분한 시간을 주거나, 아예 턴 개념을 삭제하고 클래시 로얄의 배치 시간과 유사하게 서로 비동기적인 카드 쿨타임 타이머를 부여해 더 세밀한 조작을 가능하게 하는 쪽으로 수정해야 할 것 같습니다.

> 현재 기획이 반영된 지금 프로토타입은 기획 단계에서 수정할 사항이 많아, 코드의 자세한 로직은 적지 않도록 하겠습니다. 만약 자세한 수정을 위해 정보가 필요하시다면 디엠 주시면 바로 답장하겠습니다.

## 간단한 로직 설명

- **`GameManager`** — 게임의 상태(턴 시작, 턴 진행, 턴 종료)를 담당합니다. 현재 게임 상태를 보고 게임 상태에 맞는 함수를 호출하는 역할을 합니다.

- **`BattleManager`** — 플레이어 및 적의 정보와 행동 처리를 담당합니다. 플레이어와 적 모두 같은 `BattleManager` class를 가지며, 이 클래스 내에는 덱, hp, 방어력 등의 정보를 저장합니다. 자신의 패와 큐에 카드를 보내는 역할을 맡으며, 방어력, 데미지, 효과 등의 부여 처리는 여기서 진행됩니다.

- **`HandManager`** — 플레이어 및 적의 손패를 담당합니다. 손패의 카드 정보를 저장하고, 이 정보를 게임오브젝트 형태로 (`cardVisual.cs` 참고) 플레이어에게 보여줍니다. 또한, 카드를 사용하라는 입력이 들어오면 여기서 사용할 카드를 `QueueManager`로 전송합니다.

- **`QueueManager`** — 카드 큐를 담당합니다. 여기에 속한 카드들은 `TickCooltime` 함수를 통해 쿨타임을 처리하고, 쿨타임이 다 돈 카드는 `QueueManager`에서 `Play` 함수를 통해 카드 효과를 발휘하고 덱으로 되돌아갑니다.

- **`CardDefinition`** — 카드의 정의입니다. `CardInstance`와는 다르게, 게임 시작 시 덱에 들어갈 `CardInstance`를 생성하기 위한 정보를 담고 있습니다.

- **`Effect`** — 카드의 이펙트입니다. `CardDefinition`을 ScriptableObject로 하기 위해 직렬화되어 있어, 기본 부모 클래스는 effect의 타입과 효과의 크기만을 저장합니다. 이후 `BattleManager`에서 효과를 적용할 때 적절한 자식 클래스를 생성합니다.

- **`CardEffect`** — 이 `Effect`를 보다 사용하기 쉽게 만든 클래스입니다. effect의 대상, 그리고 effect의 종류에 따라 다른 효과들에 의한 크기 변동을 고려하기 위한 `add`, `multiply`가 존재합니다. `CardInstance`는 이 `CardEffect`를 통해 자신의 효과들을 저장합니다.
